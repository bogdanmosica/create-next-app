# MCP App Specification

This app is a server that creates complete Next.js applications for you. It automates the setup of a modern web project, so you don’t have to do it manually.

What does it do?
- Generates a Next.js app with TypeScript, pnpm, and a recommended folder structure.
- Adds tools for code quality (Biome), UI (shadcn/ui), database (Drizzle ORM), and more.
- Sets up configuration files and environment variables.
- Handles errors and reports problems clearly if something goes wrong.

Why does it exist?
- To save time and avoid mistakes when starting new Next.js projects.
- To make sure every project starts with best practices and useful tools already included.
- To help teams and individuals work faster and more consistently.

This app is for anyone who wants a ready-to-use Next.js project, set up the right way from the start.
