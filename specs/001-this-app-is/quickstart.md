# Quickstart: Next.js App Creation Server

## Steps to Validate Feature

1. Submit a valid ProjectRequest via form or API
2. Confirm server generates Next.js app with TypeScript, pnpm, recommended structure
3. Request Biome, shadcn/ui, Drizzle ORM; confirm integration
4. Submit invalid/incomplete input; confirm error reporting
5. Request unsupported tool; confirm error message
6. Request conflicting configs; confirm conflict handling
7. Download generated app as ZIP; confirm contents
8. Provide Git credentials; confirm repo push
9. Validate generated app follows best practices
10. Test with both individual and team users

## Expected Results
- All scenarios pass
- Errors are clear and actionable
- Generated app is ready-to-use and follows constitution
