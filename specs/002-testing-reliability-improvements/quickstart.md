# Quickstart: Testing & Reliability Improvements

## How to Run All Tests

1. Ensure all Next.js implementation tests are located in the `nextjs-tests` folder.
2. From the repository root, run:
   ```sh
   pnpm test --dir tests/nextjs-tests
   ```
3. Review test results for unit, integration, and error scenario coverage.
4. For rollback and cleanup validation, check audit logs generated by TransactionalOrchestrator.

## Folder Structure
```
tests/
  nextjs-tests/
    [all Next.js implementation tests]
```

## Notes
- All new tests must be added to `nextjs-tests` for LLM compatibility.
- Audit logs are available for rollback and cleanup actions.
- See `tasks.md` for actionable steps to validate implementation and testing phases.
